二次関数の要点

一般形：y = ax² + bx + c（a ≠ 0）／標準形：y = a(x − p)² + q、頂点は (p, q)

判別式 D = b² − 4ac：D > 0 で異なる2点、D = 0 で接する、D < 0 で共有点なし。
